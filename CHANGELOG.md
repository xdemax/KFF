## [0.1.0] - 2026-10-24

### Добавлено
- Первая кроссплатформенная версия на Qt 6: Linux, Windows, macOS (платформенный слой `Platform.h`).
- Скачивание прошивки и ядер с GitHub (ядра - по четыре параллельно), проверка формата UF2.
- Прошивка RP2040 через сброс 1200 bps и диск `RPI-RP2`.
- Обновление ядер на SD-карте: режим MSC, резервная копия `backup_...`, копирование с `fsync`, откат при ошибке, извлечение карты.
- Linux: установка правила udev через `pkexec` (`70-karabas-...rules`), извлечение карты через udisks `Drive.Eject`.
- macOS: очистка служебных файлов (`._*`, `.DS_Store` и др.) перед извлечением карты.
- Версия в заголовке окна, в журнале и по ключу `--version`; релизы на GitHub по тегам `vX.Y.Z`.
- Автоматическая сборка в GitHub Actions под три системы.

### Известно
- Windows и macOS проверены не полностью (см. README и описание проекта).
